## Journal (Nat's project)

#### Description:
This project lets its users type out their thoughts and save each of these thoughts as individual "posts". The NLP structure in the back-end would record every typing statistics behind every keys typed, whether it's the amount of time you waited before typing again, the words the user hesitated before typing, or the typos, and etc.

I think the most impressive thing about this whole project was the nlp structure itself. One thing I liked from this project was the attention to the UI, the website's design was very clean with the usage of a mono typeface here. Another aspect that I found compelling in this project was the organization of the data.

## BEN PROJECT:

#### Description:
This project works as a small game that generates an array of clouds and lets visiting users say what the shape of said cloud reminds them of. The other users can also view what people thought the shape of the cloud reminded them of.

I might be biased here when I say that I really like the UI that's remeniscing of windows XP's design since I did the same for my final projecct for my JavaScript class, but I still stand by it.

#### Feedback:
I don't quite remember if that was already implemented but a giving the users an incentive to be more competitive about this game could be interesting; a predetermined set of words could be tied to a certain cloud, each of these words would fetch for a different amount of points. It could biased because it solely depends on what the creator decides what the cloud looks like, but they could also gather people's "cloud assumptions" into a json file, read through it and decide on which words to give more points.

I'm suggesting this because I remember someone mentioning whatever word appears the most should fetch for more points, but I think this puts early users at a disadvantage.

Constellation of strangers (Yelena's project)

#### Description:
This website lets its users write down their emotions and displays everyone's emotion on a board. The user can choose a certain emotion before writing down their thoughts (e.g. happy, sad, angry, etc.). Each users' prompts would be posted as a singular dot with a color depending on the chosen emotion and each sharing the same emotions would be linked to each other through a line, revealing a constellation.

I think the nicest thing about this project was the concept itself, it was a bit of a letdown that they couldn't show the constellation part in its glory

#### Feedback
So for my feedback I'm suggesting to find a better way to store data maybe? If it was just a repository issue then this could be ignored. Something I would love to see them try is to use Three.JS to turn the arrangement of dots into a 3D space where you can spin the whole thing around, kind of something similar to https://spiral.soot.com/, I think it could turn this project into something impressive.
